# MDN Challenge: Home Color Scheme Search

> Résolution officielle du défi d'apprentissage proposé par MDN Web Docs sur les bases du styling et la gestion des palettes de couleurs.

## À propos du projet
Ce dépôt contient ma solution pour le défi **"Home color scheme search"** de la plateforme MDN Web Docs. L'objectif est de mettre en pratique les concepts fondamentaux de la mise en page et du design des interfaces web.

## Stack technique
- **HTML5** : Structure sémantique du document.
- **CSS3** : Sélecteurs avancés, propriétés de style, gestion des couleurs et responsive design.
